1. HTML Structure (5 Marks): 

a) Create a webpage using semantic HTML elements such as <header>, <nav>, <main>, <section>, <article>, <footer>, etc. 

b) Ensure that each section of the page is clearly defined and uses appropriate HTML tags to represent the content. 

c) Add a navigation bar with links to different sections of the page. 

d) Provide a meaningful title and meta description for SEO. 

2. CSS Layout (5 Marks): 

a) Use Flexbox or CSS Grid to create a layout for the webpage. 

b) Organise content into at least three sections (e.g., header, content area, and footer) using appropriate containers. 

c) Apply styling to the containers using Flexbox or Grid properties to create a visually distinct layout. 

d) Ensure that the layout is well-structured and easy to navigate. 

3. Responsive Design (5 Marks): 

a) Implement mobile-first design by writing base styles for mobile devices. 

b) Use media queries to adjust the layout for larger screens (e.g., tablet and desktop). 

c) Make sure the page remains visually appealing and functional on different screen sizes (e.g., mobile, tablet, and desktop). 

d) Adjust font sizes, layout, and spacing for readability on smaller devices. 

4. Interactive Elements (5 Marks): 

a) Add hover effects to buttons, links, or other interactive elements. 

b) Use pseudo-classes like :hover, :focus, and :active to enhance user interaction. 

c) Apply transitions or animations to the interactive elements for a smoother experience. 

d) Ensure that interactive elements are accessible and user-friendly.
